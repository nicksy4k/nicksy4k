# Share a loan statement by link

Add a "Share link" option next to the existing Statement / Print / Copy actions on the Owed to Me tab, so you can send your sister a WhatsApp link instead of a PDF. She opens it in a browser — no account, no app, no sign-in.

## What you get

- **Create link** — from the Statement dialog, one tap creates a private link like `itemizedkeeper.co.uk/s/a8f3…` and copies it to the clipboard (plus a native Share sheet on mobile so it goes straight into WhatsApp).
- **A read-only statement page** — the same content as the PDF: total lent, repaid, outstanding, the repayment plan and upcoming instalments, and the full statement of account. Clean, printable, mobile-first. It shows your display name as the lender and the borrower's name; nothing else from your account is exposed.
- **Always up to date** — the page reads the loan live, so once you record a payment the link she already has reflects it. No re-sending.
- **You stay in control** — the Statement dialog shows the link's status with **Copy**, **Revoke**, and an optional expiry (never / 7 days / 30 days). Revoked or expired links show a plain "This statement link is no longer available" page.
- **Optional note** — the note you already type in the Statement dialog is saved with the link and shown at the foot of the shared page.

## Not included

No comments, no "mark as paid" from the shared page, and no email sending — it is a read-only view. Anyone with the link can view it, so treat it like a private URL (that is what makes it work without her signing up).
